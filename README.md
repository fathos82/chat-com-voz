# Chat com voz — Flora

Página estática (HTML/CSS/JS em um único arquivo) com chat de texto, anexos de imagem/áudio e gravação de voz via MediaRecorder. Envia as mensagens para o Chat Trigger do n8n configurado em `WEBHOOK_URL` no topo do `<script>`.

- `index.html` — página servida na raiz
- `chat-com-voz.html` — mesmo arquivo, mantido com o nome original
